# SC4RE YOUR PHONE

A fun Python script where you are the jumpscare and you have to scare your own phone.

### What it does
You run the .py file, it opens your camera, and you do horror movements + jumpscare movements to scare it. It will rank how scared it is.

### Ranking
- `WEAK` = you didn't scare it
- `UNDER EXTREME` = kinda scary
- `EXTREME` = you scared it successfully

> Glitch: Rarely it says EXTREME even if you were WEAK.
